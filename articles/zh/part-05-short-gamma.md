# 短伽马：做市商螺旋

**上一篇讲了保证金螺旋——杠杆自我喂养，直到回调变成股灾。这篇讲同一个回路，往下沉一层，沉到市场的管道里。这次的主角不是杠杆基金，而是本该让市场保持平滑的做市商。而他们在下跌中的机械对冲，恰恰做了相反的事：亲手制造了他们被付钱去吸收的那场崩盘。**

---

先看背景。2026 年 9 月 7 日，我的市场状态模块读到：

- **VIX：15.3** —— 五年 25 分位。平静。
- **SKEW：151.58** —— 83 分位。尾部保护很贵。

平静的市场，昂贵的崩盘保险。第三篇讲过这个矛盾。但背后藏着一个大多数模型看不见的东西：**昂贵的 put 保护意味着有人卖出了这些 put——而那个人通常就是做市商，现在手里拿着一个让他们在市场下跌时被迫机械卖出的仓位。**

## 伽马仓位

伽马衡量期权 delta 随标的价格变动的速度。做市商不赌方向——他们运营 delta 中性的账本，持续再平衡保持平仓。问题在于：**他们的再平衡对市场做了什么。**

- **做多伽马**（他们持有期权）：价格下跌 → 他们的 delta 下降 → 为了保持中性他们**买入**。在下跌中买入是稳定的。做多伽马的做市商是减震器。
- **做空伽马**（他们卖出了期权）：价格下跌 → 他们的 delta 上升 → 为了保持中性他们**卖出**。在下跌中卖出是放大的。做空伽马的做市商是加速器。

同样的义务——保持 delta 中性——对市场的影响却完全相反。而方向由做市商站在交易的哪一边决定。

## 做市商为什么会做空伽马

做市的经济学把账本推向一个方向。客户压倒性地想**买**保护——指数 put、下行领口、崩盘保险。总得有人卖出这些保护，而卖方拿的就是做空伽马那一侧。做市商收下权利金（和 theta），但继承了那个让他在市场下跌时被迫卖出的仓位。

这里的信号是：**SKEW 是做市商仓位的影子。** 当 SKEW 高位时，客户为尾部保护付了高价，意味着做市商的净头寸更偏做空伽马。那个被所有人读作"恐惧"的指数，同时也是"市场里藏着多少机械卖压"的标尺。

## 螺旋，带数字

我的 V9 模块（`src/dealer_gamma.py`）把这件事建模成反馈回路——和保证金螺旋同样的结构，不同的演员：

```
价格下跌 → 做市商 delta 上升 → 机械对冲卖出 → 价格继续下跌
```

用 9 月 7 日真实市场状态运行：

| 情景 | 对 -5% 冲击的放大倍数 |
|---|---|
| 无做市商伽马（基线） | 2.38× → 约 -12% |
| **净做市商伽马 -0.67（SKEW 83 分位）** | **3.07× → 约 -15.4%** |
| 同样情景，-6% 处干预 | 2.85× → 螺旋被阻尼 |

一次朴素模型叫"糟糕的一天"的 5% 下跌，单凭做市商对冲机制就变成 15% 的回撤。多出来的三四个点不是来自新闻。**它们来自市场自己的管道。** 模型估算净做市商伽马为 -0.67——这不算极端读数，只是"尾部保护很贵"——而放大已经在那里了。

这也是干预为什么重要的原因。模拟里，一旦跌幅达到 -6% 就提供流动性的干预，能把放大从 3.07 压到 2.85。不是修复，是刹车。这正是 2020 年央行应对措施在事后回顾时的样子：不改新闻，改回路。

## 经典模型为什么看不见它

标准 VaR 模型把组合当作价格接受者：你观察价格变动，计算损失。做市商螺旋以特定方式打破了这个假设——**对冲者的损失就是市场的价格变动。** 反馈和第四篇的保证金螺旋是同一种形状，所以我用同一个框架建模它们：

```
组合杠杆  → 保证金追缴 → 强制卖出 → 价格下跌 → 更多追缴
做市商短伽马 → delta 对冲 → 机械卖出 → 价格下跌 → 更多对冲
```

一个回路在杠杆基金的账本里，一个回路在做市商的账本里。同样的数学，经典模型同样的盲区：**由市场自己造成的部分损失。**

## 三句话带走

1. **SKEW 不只是恐惧——它是仓位地图。** 高 SKEW 意味着有人在做空伽马，而这个仓位会把普通的下跌变成机械卖压。当 SKEW 处于高位，平静的 VIX 是更安静的危险，不是更安全。

2. **低波动 + 昂贵的保护 = 累积的做空伽马。** 感觉最安全的状态（平静 VIX）往往正是波动率卖方堆积的状态。崩盘风险不在波动率水平里，在它底下藏着的做市商账本里。

3. **建模流量，不只是仓位。** "做市商做空伽马"描述的是一个状态。损失只有在你建模**流量**——每一次下跌之后跟着的机械卖出——时才出现。状态模型看不见它；回路模型抓得住。
