# 我用保险精算的方法，做了一个股灾压力测试工具

**为什么你的组合在危机时"失灵"——以及保险公司给飓风定价的方法，能教会我们什么。**

---

2020 年 3 月，标普 500 在 33 天里跌了 34%。比特币跟着跌，黄金跟着跌，连"防御性"的股息股也跟着跌。你投资组合理论里所有"低相关"的资产，在那一刻全部同向运动——向下。

这不是市场的 bug，这是危机时市场的固有特征。而它恰恰是**所有建立在正态分布假设上的风险模型集体"失明"**的时刻。

我花了几个月做了一个不会失明的工具。这一路踩的坑，值得聊聊。

## 正态分布的问题

大多数组合风险工具假设收益服从正态分布。数学优雅、尾部很薄、模型可解。只有一个问题：**市场不读教科书**。

正常时期，资产间的相关性大概在 0.3~0.6。危机一来，相关性收敛到 1.0——所有资产一起跌，你精心"分散"的组合瞬间变成一注集中的赌注。

标准的 VaR（在险价值）模型算的是"最差的 1% 情况"。但当真实分布有肥尾——当那 1% 的事件比任何正态分布能允许的都糟得多——这个数字就危险地乐观。模型告诉你"桥能撑住"，桥塌了。

## 保险业早就想明白了

我出身制造业和质量管理，这个背景教会我一件事：**罕见事件才是杀死你的那个**。一个 0.1% 概率失效的零件没问题——直到它恰好是撑起整架飞机的那个零件。

保险公司很久以前就解决了这个问题。给飓风保单定价时，他们问的不是"平均损失是多少"，而是四个更具体的问题：

1. **危险层（Hazard）**——飓风到底怎么发生？（频率、强度、路径）
2. **暴露层（Exposure）**——路径上有什么？（房子、人、资产）
3. **脆弱性层（Vulnerability）**——每样东西对给定的风暴有多脆弱？（屋顶结构、施工质量）
4. **损失层（Loss）**——美元损失是多少？（以及超过任意损失水平的概率）

这就是**巨灾模型（Catastrophe Model）**——让保险公司给"不可定价的东西"定价的四层框架。核心动作是把"灾难如何发生"和"灾难摧毁什么"分开。**金融危机也是灾难**，所以我用同样的框架给股票组合建了一套。

## 四层架构

### 第一层：危险层——股灾怎么发生

我用三种方式生成股灾情景：

- **6 个历史股灾**：2008 金融危机、2020 新冠、2022 中概股闪崩，外加三个。真实事件、真实量级、真实板块特征。
- **SDE 跳跃扩散模型**：危机不是爬过来的，是跳过来的。带跳跃项的随机微分方程（SDE）同时刻画正常时期的缓慢漂移和危机时刻的暴力跳跃。参数用 R 的 `yuima` 包从真实行情估计。
- **系统动力学**：隐藏的反馈回路。杠杆玩家被追缴保证金 → 被迫卖出 → 卖压把价格打得更低 → 更低的价格触发更多追缴。**这个回路——不是"新闻"——才是把回调变成股灾的东西**。我把它建模成显式的反馈系统。

### 第二层：暴露层——你拿的是什么

你的组合：持仓、行业、市值分布。没什么花哨——但它极其重要，因为同一场危机打银行股和公用事业股，完全是两回事。

### 第三层：脆弱性层——你的组合有多脆

真正的数学在这里：

- **下行 beta + 行业固定效应**：不是"这只股票波动多大"，而是"市场跌的时候它跌多少，控制行业因素之后"。
- **Vine copula 尾部依赖**：这是对"相关性收敛到 1"问题的正面回答。Vine copula 显式建模资产之间的依赖结构——包括**尾部依赖**（"糟糕的时候，大家一起糟糕"）。这是取代失效的正态分布假设的那块拼图。
- **XBRL 财务脆弱性**：解析 SEC 年报（XBRL 格式），用公司实际披露的数字给每家公司打财务脆弱性分。杠杆、流动性、债务期限——决定一家公司是熬过下行还是变成被迫卖家。
- **情绪 NLP 校准**：因为市场也是叙事。用 NLP 分析散户评论，当情绪亢奋（风险顶峰）或恐慌时调整模型参数。

### 第四层：损失层——你会亏多少

跨 10000+ 事件的蒙特卡洛模拟，输出：

- 期望损失
- VaR 95% / VaR 99%
- **CVaR**（尾部内的平均损失——真正重要的那个数）
- 最大回撤
- **超越概率曲线（EP 曲线）**：损失超过 X 的概率，对每个 X。这就是保险业的曲线，移植到组合上。
- 行业损失归因：到底**是哪些持仓**在伤害你。
- 仓位建议：基于风险预算——环境越动荡，模型告诉你的仓位越小。

## 这个工具教会我的事

构建过程就是和自己假设的持续争论。V1→V8 的版本史，基本就是一份踩坑清单：

- **V1**：核心框架。蒙特卡洛 + 历史股灾 + 下行 beta + VaR/CVaR + EP 曲线。能跑，但也天真——单个历史股灾不是分布。
- **V4（系统动力学）**："啊哈"时刻。加入杠杆反馈回路后，损失数字变化巨大——因为危机是**级联**的，单次模拟根本看不到这一点。
- **V5（vine copula）**：替换相关性假设。这一层让工具对危机行为诚实。正常时期模型说"你没事"，vine copula 说"你有事"。
- **V6（SDE 跳跃扩散）**：显式建模跳跃。危机不只是大幅波动，是**不连续**的波动——完全不同的数学。
- **V7（XBRL + 情绪）**：加入基本面和叙事。市场既是一台机器，也是一群人。
- **V8**：完整 Streamlit 网页应用——因为跑不起来的模型是论文，不是工具。

## 三句想对过去的自己说的话

1. **薄尾模型不是"简化"，是谎言**。图方便可以用，危机规划千万别用。
2. **级联才是故事**。坏日子和股灾的区别是反馈回路。你的模型没有回路，就是在建模另一个事件。
3. **尾部依赖是全部重点**。分散化在正常时期有效，在你最需要它的时候失效。直接建模依赖结构，别假设它不存在。
