# 系统动力学：当股灾变成自己的引擎

**2026 年 9 月初，VIX 处于五年低位（平静），SKEW 却接近历史高位（恐惧）——一个既安静又瑟瑟发抖的市场。这个矛盾是上一篇的主题。这篇讲一个比"昂贵的尾部保险"更危险的东西：当杠杆藏在平静市场里时会发生什么。因为带杠杆的股灾不是事件，它是一台烧自己燃料的引擎。**

---

机制很简单，而且近几十年里它已经终结过两次市场（2008 年、2020 年 3 月）：

1. 价格下跌 5%。
2. 保证金账户突然资不抵债。
3. 经纪商强制平仓。
4. 强制卖出把价格再压低 5%。
5. 更多账户爆仓。循环。

这就是**保证金螺旋（margin spiral）**，一个正反馈回路。而它和经典风险模型能处理的一切之间的分界线在于：**在螺旋里，下跌不是新闻造成的——下跌是由上一次下跌造成的。市场变成了自己的冲击源。**

## 为什么经典风险模型对它是盲的

标准 VaR 模型活在一个单向世界里：

```
新闻 / 利率 / 盈利  →  价格变动  →  组合亏损
```

市场砸你，你算损失。干净、外生、单向。

螺旋活在另一个世界里：

```
价格下跌  →  保证金追缴  →  强制卖出  →  价格继续下跌
```

方向反了——而且它循环。**你不只是被动承受市场冲击；你自己的杠杆在创造冲击。** Dean Lee（一位对衍生品有深度了解的读者）在我第一篇文章下的评论，恰恰点中了这件事：

> "在财产保险里，飓风不读保单。在资本市场里，危险层是由金融合约本身创造的。"

他说得对——这正是我的框架里回应他的那块：**危险层必须建模合约，而不只是建模事件。**

## 保险类比，被磨锋利了

保险公司给飓风定价。飓风是外生的——它不会因为更多人买了沿海保单而变得更强。这个假设让四层巨灾模型干净、可计算。

股灾不同。股灾**会**因为更多人加杠杆而变得更深。系统里的保证金债务越多，螺旋的燃料越足：

- 低杠杆市场跌 10% 是回调。
- 同样跌 10%，在高杠杆市场会触发平仓，把 10% 变成 30%。

这就是财产保险永远不会面对、而金融风险建模无法忽视的**内生性**。危险是系统状态的函数——包括系统里每个人的仓位。

## 建模这个回路

反馈回路不是概率分布。它是**一个符号故意放错的微分方程**——你要建模的是迭代，不是事件。

在我的开源 Crash Simulator 的 `src/system_dynamics.py` 里，螺旋被建模成存量-流量回路：

```
t 时刻的状态：
  价格、保证金债务存量、保证金阈值、强制卖出流量

迭代 t → t+1：
  价格下跌      → 净值跌破阈值
  阈值被击穿     → 强制卖出流量激活
  卖出流量      → 价格进一步下跌
```

每一次迭代喂养下一次——循环一直跑到两件事之一发生：系统完成去杠杆（弱手被卖光），或者外部力量介入。

最后这一点很重要。**2020 年和 2008 年的救市不是"修复新闻"。** 它们是打断回路——央行提供流动性，让强制卖出停止喂养价格下跌。当你把股灾建模成事件，干预像是边角故事；当你把它建模成回路，干预**就是**故事本身。

## 螺旋教的三件事

1. **杠杆不是波动率——它是下跌的加速度。** 波动率告诉你波动有多大；杠杆告诉你一次下跌会如何自我喂养。平静的 VIX 对藏在底下的杠杆什么也说不出来。

2. **股灾是过程，不是点。** EP 曲线告诉你亏多少；系统动力学告诉你**为什么**亏——以及为什么同样的冲击，在不同系统状态下会产出完全不同的结局。

3. **干预是设计输入，不是事后补丁。** 如果你的模型没有"回路被打断"的机制，那么你的尾部情景在恐慌情形下会系统性高估，而在强制去杠杆情形下又会系统性低估。

## 下一步：同样的逻辑，往下一层

同样的反馈逻辑活在微观结构层，以一种上过不止一次新闻的形式：**做市商 short gamma。** 卖出波动率的期权做市商被迫做机械对冲——市场涨他们买，市场跌他们卖。在下跌中，他们的机械对冲变成了向下跌市场的强制卖出，亲手制造了模型试图度量的那个尾部事件。同一个回路，不同的演员。

这是我正在做的 V9 方向——把反馈层从组合杠杆延伸到做市商对冲流。公开构建一直在回报：路线图越来越锋利，而评论区比代码更值钱。
