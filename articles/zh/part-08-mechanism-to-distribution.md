# 单点 3.07 倍隐藏了什么：从机制到分布

**第五篇报告过：在 9 月 4 日市场状态下，一个 -5% 的冲击会变成 -15.4%——3.07 倍放大。一位读者提出了整个系列最有用的一个问题："后续应该是非线性的、不确定的——是一系列后果的概率分布，而不是一个单点数字。"他说得对。这篇文章就是答案：V9-P4 给机制套上蒙特卡洛外壳，而那 3.07 倍，其实是一条一直延伸到 -32% 的分布的中位数。**

## 先兑现上一篇承诺的更正

还有一位读者抓到了第六篇的一个数据 bug：我把市场状态标成了"9 月 7 日"——而那天是美国劳动节，休市。Cboe 的 VIX 历史文件里混入了一行假日占位数据，我的管道直接取了最后一行。已修复（过滤周末 + 让 VIX 与 SKEW 对齐到它们**共同**的最新交易日）。那篇文章更正后的状态：**9 月 4 日，VIX 14.53（18 分位）、SKEW 151.58（83 分位）**。结论不变——低波动、昂贵的尾部保护、短伽马累积。日期现在是对的，继续。

## 3.07 倍是怎么来的

做市商伽马模块跑一个单行反馈环：

```
对冲流 = -κ · 净伽马 · 价格变动      # 做市商做 delta 对冲
下一步  = α · 当前变动 + β · 对冲流   # 他们的对冲又推动价格
```

净伽马估计为 **-0.666**（由 SKEW 83 分位推得），叠加 -5% 冲击，循环复利到 -15.4%——**3.07 倍**。确定性、可复现、单条路径。

读者的质疑恰好打在两个输入上：

- **净伽马是估计的，不是观测的。** 没有免费的 OCC 期权持仓数据——-0.666 是从 VIX/SKEW 分位推出来的。符号和量级方向在结构上是对的，但它不是实测持仓。
- **-5% 是情景，不是事实。** 我们选它来*测试*机制。下一次真实的冲击会更大、更小、更快、更慢。

建立在两个假设上的单条路径，是*故事*，不是预测。修复的办法不是放弃机制——而是把假设显式化为分布，看看机制在所有假设下会产出什么。

## 模块：机制进，分布出

`mc_mechanism.py` 原样保留确定性螺旋，外面加一个采样外壳：

| 输入 | 先验（有文档、可配置） |
|---|---|
| 净伽马 | 截断正态：均值 -0.666，σ 0.15，范围 [-1.0, 0.0]（状态隐含短伽马） |
| 冲击大小 | 截断正态：均值 -5%，σ 2%，范围 [-12%, -1%] |
| 路径数 | 2,000 条，固定种子（可复现） |

每条路径：抽一组（伽马，冲击）→ 跑同一条确定性螺旋 → 记录回撤。输出：后果分布 + 超越概率曲线（EP 曲线）——把巨灾建模的标准输出套到机制层上，而不仅仅是历史重演。

## 分布说了什么

| 回撤 | 数值 |
|---|---|
| 单点路径（第五篇） | **-15.4%**（3.07 倍） |
| 中位数（p50） | **-15.3%** |
| p10（10% 的路径更糟） | **-22.8%** |
| p1（1% 的路径更糟） | **-28.1%** |
| 2,000 条中最差 | **-32.1%** |

**单点 3.07 倍就是中位数。** 它从来没错——它只是不完整。读者的观点正中要害：报告分布之后，诚实的标题变成*"在这个状态下，-5% 的冲击会产生 -15% 到 -32% 之间的后果，中位数接近 -15%，百分之一尾部接近 -28%。"*

EP 曲线用风险报告真正使用的形式说话：

| P(回撤 ≤ …) | 概率 |
|---|---|
| -10% | 95% |
| -15% | 52% |
| -20% | 21% |
| -25% | 约 5% |

一半的路径越过 -15%；五分之一越过 -20%。这就是那个单点数字藏起来的分布。

## 这对干预故事意味着什么

第四/七篇的 backstop（2020 式：切断强制卖出的*流*）此前是在单条路径上演示的。分布形式下它表现得完全符合预期——压缩尾部，不动中心：

| 尾部指标 | 无干预 | 切流量 |
|---|---|---|
| p1 | -28.1% | **-26.1%** |
| 2,000 条中最差 | -32.1% | **-30.2%** |
| 中位数 | -15.3% | -15.3%（不变） |

切流量不改变*平均*路径的行为——机制照样放大。它改变的是*尾部*：稀有、最坏的路径变浅。这正是分布形式下的 2020 故事，也是"美联储帮了点忙"与"美联储缩短了损失分布的左尾"之间的差别。

## 诚实的边界

- **先验是有文档的假设，不是校准拟合。** 分布的宽度是*选出来的*（伽马 σ 0.15、冲击 σ 2%）。真实宽度需要真实持仓数据——恰好是那些不免费的数据。要点是*结构*：机制 + 显式不确定性 → 尾部分布。更好的先验会移动确切的分位数。
- **内核仍然是确定性的。** 这个模块是在机制*周围*加不确定性；它还没有让伽马在路径中逐条演化（危机中途的状态切换、级联违约）。那是下一步。
- **EP 概率是模型内的。** P(回撤 ≤ -20%) = 21% 的意思是*在这些先验和这个机制下*，不是对日历时间的声称。

## 下一步

机制层问"什么样的结构能产生这个尾部"；分布层问"在已知与未知面前，尾部有多大"。剩下的缺口是系列里反复出现的那个：*隐含*状态——做市商持仓、保证金阈值、期权流——从账本里测量，而不是从指数里推断。那个数据很贵。在那之前，这类模型就是让不确定性显形、而不是藏进一个单点数字的办法。
