# 螺旋为什么会停：伽马翻转

**做市商短伽马螺旋是这个系列最好的故事：下跌触发机械对冲，机械对冲加深下跌。第五篇把它变成了 3.07 倍；第八篇展示了那个数字是一条延伸到 -32% 的分布的中位数。但有一件事一直不舒服：真实世界里，螺旋会停。2020 年 3 月没有跌到零——它先企稳，然后反弹。这篇文章补上这个缺口：V9-P5 把伽马翻转加进内核，机制终于能解释一场崩盘的完整两半——它为什么加深，以及它为什么结束。**

## 那个不舒服的事实：螺旋会终止

这个系列到目前为止的每个机制都是自我放大的。短伽马催生卖压，卖压加深短伽马压力，保证金催缴级联。把循环一直跑下去，你会得到 -32%、-50%、更糟。市场不会这样。连 2008 和 2020 都见底了。

为什么？因为驱动螺旋的*持仓*不是固定的。做市商做空伽马，是因为卖出尾部保护有利可图。当尾部真的到来，这个交易变得剧烈亏损——隐含波动率爆炸，做市商的账本翻转：下跌途中被迫卖出，波动率飙升重新定价持仓之后，又机械地被吸引去*买入*。短伽马变成长伽马。卖出的引擎耗尽燃料。

这就是**伽马翻转**——把崩盘变成底部的机制。

## 模型：在第五篇内核上加一条演化规则

V9-P4 的诚实边界说，内核还没让伽马在路径内演化。`gamma_flip.py` 恰好加一条规则：

```
伽马从 -0.666 开始（短伽马）                    # 第五篇的估计
一旦累计回撤越过翻转阈值：
    伽马向 +0.80 收敛（深度长伽马）             # 波动率飙升翻转做市商账本
```

其他一切——`对冲流 = -κ·γ·价格变动` 的反馈、α/β 动力学——原封不动。一条规则，一组新参数：翻转*何时*发生（阈值）、落地*多狠*（目标）、咬合*多快*（速度）。

## 翻转对单条路径做了什么

默认阈值（10%）下：

| 路径 | 回撤 | 放大倍数 |
|---|---|---|
| 无翻转（第五篇基准） | **-15.4%** | 3.07 倍 |
| -10% 处翻转 | **-13.8%** | 2.76 倍 |

价格路径讲述真实的故事——它*企稳*了：

```
无翻转：  1.00 → 0.95 → 0.92 → 0.89 → 0.87 → 0.86 → 0.85 → … → 0.846
有翻转： 1.00 → 0.95 → 0.92 → 0.89 → 0.87 → 0.870 → 0.866 → 0.864 → 0.862（走平）
```

翻转在第 3 步触发（伽马从 -0.666 翻到 +0.80），下跌停止。不是 V 型反弹——是*截断*的崩盘。这个区别很重要。

## 翻转的时机就是一切

扫描阈值——即问"市场在翻转前容忍多少伤害"：

| 翻转阈值 | 回撤 | 放大倍数 | 翻转步 |
|---|---|---|---|
| -5% | -11.9% | 2.39 倍 | 1 |
| -8% | -13.0% | 2.61 倍 | 2 |
| -10% | -13.8% | 2.76 倍 | 3 |
| -15% | -15.4% | 3.07 倍 | 10（太晚） |
| -20% 以上 | -15.4% | 3.07 倍 | 从不 |

模式残酷地单调：**市场"自我修复"越晚，伤害越趋近于完整螺旋。** 阈值在 10% 以下时翻转实质性地截断崩盘；到 15% 已经太晚——伤害在持仓翻转之前就造成了。换句话说，阈值不是细节，它们是全部游戏。

## 分布视角（第八篇的语言）

伽马0 / 冲击 / 阈值都不确定时（与 V9-P4 相同的先验，2,000 条路径）：

| 指标 | 无翻转 | 有翻转 |
|---|---|---|
| 中位数 | -15.5% | **-14.0%** |
| p10 | -22.7% | **-19.4%** |
| p1 | -28.6% | **-23.7%** |
| 最差 | -33.4% | **-27.2%** |

翻转在 80% 的路径中触发，而且它做了第八篇展示干预会做的事：压缩*尾部*，不动中心。中位数移动约 1.5 个百分点；p1 移动约 5 个百分点；最差移动约 6 个百分点。机制的自终止，构造上就是一个尾部缩短器。

## 诚实的分工

这是我想谨慎的部分。**伽马翻转止住崩盘；它不逆转崩盘。** 在这个模型里，价格企稳——不反弹。2020 年 3 月的 V 型反弹来自另一台引擎：美联储的 QE，这个系列把它建模为*干预*（切流量）。所以完整的 2020 故事，用机制的术语说，是两个独立的幕：

1. **波动率飙升翻转做市商伽马** → 卖出螺旋被截断（本模块）。
2. **流动性注入逆转资金流** → 企稳变成复苏（干预模块）。

把这两幕混成一个"市场会自我纠正"的叙事是错误的——这正是产生糟糕政策结论的那种混淆（"不需要干预，市场会自我修复"）。翻转是真实的，而且它*不是*干预的替代品。它把失控的螺旋变成受控的企稳；这个企稳能否变成复苏，是另一个问题，政策驱动的问题。

## 边界

- 翻转规则是**有文档的简化**，不是拟合模型。真实的翻转更混乱（涉及具体的做市商账本、波动率曲面重新定价、翻转*内部*的强制清算）。
- 阈值没有用数据校准。扫描是读它的诚实方式：这就是尾部对翻转时机的敏感度。
- 这个模块*还*没有做的：对翻转*内部*的级联建模——那些在账本转正之前就爆掉的基金。那是下一级台阶：短伽马 → 波动率飙升 → 强制清算 → 伽马翻转作为级联的*终点*，而不是起点。
