## 一、一句话定位

**给裸奔的散户做裤衩。**

牛市里裤衩没人需要（身上披满鲜花）；崩盘那天，它是唯一能想起的东西。

## 二、受众 / 目的 / 边界

- **受众**：有真实持仓、没有机构团队、从未系统学过风险机制的散户。
- **目的**：把学术界和机构圈的风险机制，翻译成散户能懂的语言、能用的工具、能执行的规则。
- **我们做**：机制文章（认知）+ 开源工具（算力）+ 事前清单（动作）。
- **我们不做（红线）**：荐股、预测点位、追热点、"听我的买这个"。任何承诺避险效果的内容也不做（既做不到，也有合规风险）。
- **价值主张**：市场大跌时，你是"想起裤衩"的人，不是裸奔的人。

## 三、检验标准

> 旧的候选（"明天跌20%，读这篇的散户会不会少做一件蠢事"）已废弃——
> 事前无法检验、事后无法归因、隐含避险承诺。检验标准只检验我们可控的环节。

- **复述测试（写之前）**：这篇的核心机制，能不能用"一句人话 + 一个类比 + 一个数字"讲完？讲不出来 = 作者没想透，先想透再写。
- **记忆测试（发之后）**：三天后，读者还能不能记住"一个类比、一个数字、一条规则"？评论区、私信、转发语是考场。

## 四、表达公式（每篇强制四步）

1. **机制**：学术界/机构圈在做什么（如：危机时相关性趋1）。
2. **类比**：一个普通人身体里已有的图像（如：分散投资 = 以为各房间独立，其实共用一个承重墙）。
3. **数字**：我们的代码跑出来的（如：10% 的冲击，落地 18%）。
4. **判断**：散户该知道什么（如：危机时不要相信分散，要相信事前定好的规则）。

## 五、世界观（两段论）

> 上一版"危机不是外来的黑天鹅，而是市场结构内生的"已废弃——把源头与传导混为一层。

**危机的导火索是外生的，危机的发展是内生的。**

- **外生层（源头，不可控）**：技术革命、生产力-生产关系矛盾、地缘重构、疫病、自然灾害、货币体系变化。特点：人们知道不对，但短期无人能改（集体行动问题）。不可预测，只能观测。
- **内生层（传导，可建模、可控）**：杠杆强平螺旋、相关性趋1、做市商 gamma、政策兜底预期、流动性冻结。特点：跨市场传导（股市→债市→外汇→商品，2020.3 是完整实例）。
- **我们的位置**：站在内生层。外生决定"何时点燃"，内生决定"烧多大"。
- **灰犀牛的正解**：最危险的外生不是地震（急性、人人知道怕），而是慢性积累、人人知道、但无人能单独停下来的那类（债务周期、生产力-生产关系矛盾）——不是不知道它会来，而是知道它在靠近，但每个个体停下来都会先死。
- **一句话**：散户无法控制外生，但能通过理解内生来准备——这就是裤衩存在的理由。

## 六、内容引擎（双轨制）

- **轨道 A（权威）**：Fat Tail Notes 深度系列 → 少数专业读者 → 背书、接单、作品集。
- **轨道 B（需求）**：短平快回答真实问题（知乎问题、Reddit）→ 大众读者 → SEO、算法推荐。
- **共用内核**：同一套代码机制，不同包装与入口。
- **选题来源升级**：学术前沿是趋势信号（arXiv/NBER/ECB/中文期刊）——真正的锚点不是"读者问什么"，而是"学术在争论什么"。每篇回应一篇反驳我们的论文，用代码验证，是轨道 A 的下一个形态。

## 七、平台策略（v0.2 新增）

- **英文是主战场**：DEV.to（零审核、发完即归档；流量靠社区互动，沉底自担）。英文内容 = 信用资产、接单背书。
- **中文是存续频道**：知乎低频（≤1 篇/周）+ 彻底去模板，发完不查数据，不被平台绑架。不申诉、不重投被限流内容。
- **归档权威出口**：Gitee + GitHub 仓库 `articles/`（双语双版本），平台可以塌，仓库不塌。
- **平台合规规则：公式固定，表层自由**——标题、开头、结尾每篇单独写，禁止复制任何固定句（AI 声明、开源代码行、同步声明一律换措辞或省略）。
- **总原则**：谁都不能绑架节奏。平台限流/审核是发布方式的信号，不是系列主线的判决。
